# Personal Portfolio Website

## Project Description

This project is a personal portfolio website developed to showcase my
profile, technical skills, education, projects, and contact information.

The website provides a clean and responsive interface that allows visitors
to learn about my academic background, technical abilities, projects, and
ways to contact me.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Website Features

- Responsive personal portfolio website
- Home/Hero section
- About Me section
- Technical Skills section
- Education section
- Projects section
- Project descriptions and technologies
- Contact information
- Contact form
- GitHub and LinkedIn links
- Navigation between website sections
- Hover effects and animations
- Responsive layout for different screen sizes
